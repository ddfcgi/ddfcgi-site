Where Can I Find MAS 90 / 200 Manuals?

If you are using Sage MAS 90 or MAS 200 versions 4.3 or 4.4 you can print the help topics as a document.How?From the main MAS 90 menu select Help –> Help Topics.Under Contents scroll all the way to the bottom and open the last topic “Module PDFs”.You can then open and print the PDF documentation from the list.While these are not manuals in the strictest sense, they do provide a document that you can use to guide you through your MAS 90 software and help with understanding how the software works.
